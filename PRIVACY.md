# SwiftCopy privacy policy

_Last updated: October 25, 2026_

SwiftCopy is a file copy manager for Windows made by yasmanyfmSoft.

**SwiftCopy does not collect, store, or send any personal information.** It has no accounts, no ads, no analytics and no telemetry, and it never connects to the internet.

What stays on your PC:

- **Your settings** (theme, copy options, recent destination folders) are saved in your Windows user profile so SwiftCopy remembers them.
- **A troubleshooting log** (`SwiftCopy.log`) records SwiftCopy's own decisions, such as "Ctrl+V taken: copied 3 items into a folder". It never contains file contents or anything you type. You can open or delete it at any time.

**About Ctrl+V in File Explorer:** when you turn on "Use SwiftCopy when I press Ctrl+V", SwiftCopy watches for the Ctrl+V key combination only while File Explorer or the desktop is the active window and its file list is focused. It does not record, store or send any other keys you press. You can turn this off in Settings.

SwiftCopy only reads and writes the files and folders you ask it to copy or move.

Questions: open an issue at https://github.com/yasmanyferrerm-source/SwiftCopy/issues
